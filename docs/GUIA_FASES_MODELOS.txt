Criterio general de optimización de cuota:
- Flash (Medium): La mejor relación costo/beneficio. Ideal para JSON, datos,
  UI, animaciones, balances numéricos y tests automáticos.
- Pro (Medium): Para cambios estructurales que involucran múltiples sistemas
  de simulación o refactorizaciones moderadas.
- Pro (High): Reservado para modificaciones en el layout de memoria binaria
  (PackedInt64Array en FightSim), cambios de protocolo de red (GAME_PROTO),
  o depuración de desincronías complejas de rollback tick a tick.
